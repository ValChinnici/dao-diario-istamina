# DAO Diario Istamina

PWA for managing histamine intolerance (DAO): food search against the SIGHI compatibility table, and a meal diary with an automatic "take Daosin" rule. Bilingual IT/EN, dark mode, installable on iOS and Android.

**Live app**: https://valchinnici.github.io/dao-diario-istamina/

All data (meal diary, symptoms) stays **only on the device** in IndexedDB. No backend, no account, no network calls other than Google Fonts.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Data

`src/data/sighi-foods.json` is generated by `scripts/extract_sighi.py` from the official SIGHI PDF (`SIGHI-FoodList_IT_Histamin_alphabetisch_inKategorien.pdf`), using positional column extraction to correctly handle multi-line rows.

## Icon

The PWA icons in `public/icons/` are generated from `assets/icon-source.svg` via `node scripts/gen_icons.mjs` (requires the `sharp` dependency). Re-run the script after any change to the source SVG.

## Deploy

Every push to `main` automatically publishes to GitHub Pages via `.github/workflows/deploy.yml`.

## Disclaimer

This app is not a medical device and does not replace medical advice. Guidance is based on the SIGHI table and is a general guideline, not a guarantee of individual tolerance.
